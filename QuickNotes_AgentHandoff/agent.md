# agent.md --- 项目交接入口

## 项目

面向 Windows 11 x64 的桌面便签软件。AI Agent 用于开发，产品本身不内置 AI
Agent。

## 当前状态

-   产品基线：`docs/product/PRD_v1.0.md`
-   当前阶段：B 阶段------数据存储与备份原型。
-   A
    阶段窗口/托盘原型：用户反馈"基本验证通过"；边界测试仍需按实际记录标为通过、失败或未测。
-   当前候选：`.NET 10 + WPF`；数据原型候选：SQLite。
-   最终技术选型尚未完全冻结。
-   用户优先保证产品质量，Rust 可后续使用；B 阶段不引入 Rust FFI。

## 本阶段目标

证明数据层能正确持久化便签，并在写入失败、备份损坏、恢复中断等情况下不静默丢失原始数据。

## 开始前

阅读 `AGENTS.md`、`docs/product/PRD_v1.0.md` 和
`docs/agent/Agent对接文档_B阶段.md`。

## 工作流程

1.  检查仓库、SDK、依赖和现有文件。
2.  先输出环境检查结果、实施计划和风险。
3.  按 B0、B1、B2......小步实现。
4.  每一步运行测试并如实报告。
5.  不改 PRD 已确认规则；遇到歧义先提出 ADR/问题。
6.  当前不做完整 UI、托盘、快捷键或 Rust 集成。
7.  只使用临时测试目录与合成数据。

## 第一条任务

执行 B0 与 B1：环境/仓库检查；最小数据模型、SQLite schema、schema
版本、事务化
CRUD、版本冲突保护和集成测试。暂不实现自动备份轮换、整库恢复或正式 UI。
