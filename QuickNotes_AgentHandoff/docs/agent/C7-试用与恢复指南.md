## 4. 启动与首次运行

```powershell
$data = Join-Path $env:TEMP ("QuickNotes-C7\" + [guid]::NewGuid().ToString("N"))
.\artifacts\quicknotes-trial-framework\QuickNotes.Desktop.Wpf.exe --data-root $data
```

- 普通启动：显示管理中心；首次运行初始化 `notes.db`、`application-state.json`、`drafts/`、`logs/`。
- 登录启动模拟：加 `--startup`，不显示管理中心，由托盘和桌面便签维持运行。
- 同一数据根只允许一个实例；第二次启动会尝试激活第一实例。
- 数据层 Ready 时进入正常使用；恢复、阻断或只读诊断时显示启动/诊断窗口，不会静默创建空库继续写入。

## 5. 核心试用闭环

1. **新建**：管理中心点击“新建”；便签窗口应立即出现且焦点在正文，不需要先在管理中心输入文字。
2. **编辑与保存**：在便签窗口输入；自动保存和 Ctrl+S 均可用；观察保存/草稿状态，不要把“没有异常”当作保存成功。
3. **管理中心**：切换 Active/归档/回收站；搜索、分类/标签筛选、排序、多选/批量/撤销/副本。
4. **生命周期**：归档后可恢复；恢复后按规则回到正常/隐藏状态；回收站可恢复或永久删除。
5. **双向同步**：管理中心与便签窗口修改应实时同步，不需要切换便签。
6. **顶栏**：设置中启用顶栏动作后，已存在和新开的便签窗口都应刷新；“更多”菜单应可展开。

## 6. 备份与恢复

### 6.1 备份

1. 打开管理中心“备份与恢复”。
2. 首次可配置备份目录，或稍后配置；目录必须在临时数据根之外、可写且不是当前数据根。
3. 配置后执行手动备份；列表应显示包、校验结果和状态。
4. 自动备份在配置目录后启动：启动立即检查、15 分钟周期、唤醒补检查；状态写 `backup-status.json`。

备份包是 SQLite 一致性快照 + manifest + SHA-256；不包含草稿、设备设置、迁移保护快照；包未加密。

### 6.2 恢复

1. 先确认备份包校验通过；恢复预检会显示格式/schema/数量等信息。
2. 恢复前会保存并冻结编辑，旧会话失效；恢复后宿主刷新。
3. 恢复使用同卷 staging 与 `File.Replace` 切换；失败会回退，回退失败会持久阻断写入。
4. 恢复完成后核对便签数量/关系；草稿不进入整库替换，保留本地恢复入口。

**不要手工删除** `migration-protection/`、`.quicknotes-restore-*`、保护包、`rollback.db` 或未完成 journal；它们是诊断/恢复证据。

## 7. 阻断、恢复失败与诊断

- 启动状态在 `application-state.json`；恢复日志在 `recovery-journal.json`；诊断日志在 `logs/quicknotes-YYYYMMDD.log`。
- 写入阻断（`writesBlocked=true`）不会因重启自动解除；按启动/诊断窗口提示检查数据目录、保护快照与回退库。
- 恢复中断会保留 journal/staging；不要用空库覆盖，不要删除证据后再重试。
- 需要人工判断时，保留整个临时数据根和备份包，记录时间、操作步骤、日志尾部；不要附带真实用户正文。
- 本版本没有自动修复/一键解除阻断入口；C6 的真实 VHD/ACL/断电场景未全部验证。

## 8. 停止与清理

```powershell
# 关闭该数据根的 QuickNotes 进程后，仅删除本次临时根
Remove-Item -LiteralPath $data -Recurse -Force
```

- 不要删除真实用户数据根或共享备份目录。
- 试用结束后检查没有遗留托盘图标/进程；热键注册随进程退出释放。
- 若要保留诊断证据，先复制日志/状态/journal 到评审证据目录，再删除临时根。
