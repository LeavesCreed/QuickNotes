## 4. 覆盖亮点

- 首次运行：状态 `Initializing` → schema 初始化 → 校验 → `Ready`；失败不写 Ready；可显式重试。
- 单实例：数据根锁文件在 DB/草稿/日志之前取得；第二实例真实进程探测激活；不同数据根互不冲突。
- 缺失/损坏/状态缺失/WAL/恢复日志未完成/损坏状态：均进入安全模式或恢复，不自动建空库、不删除 sidecar/恢复产物。
- 持久阻断：写入阻断状态原子写；新协调器/重启读取后仍 `WriteBlocked`；重启不自动解除。
- 缺库/阻断恢复：选择已验证备份，完整校验、隔离当前库、发布后校验、清除阻断；失败保留 staging/quarantine，不报成功。
- 恢复产物：`.quicknotes-restore-*`、`.quicknotes-quarantine-*.db`、保护快照、临时包均保留。
