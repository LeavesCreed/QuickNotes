# C5-B 桌面行为人工检查清单

> 自动化测试已覆盖会话注册、启动参数、启动注册抽象、快捷键解析/去重、窗口 clamp。以下矩阵必须在 Windows 11 x64 实机执行；未执行项不得标记为通过。

## 1. 独立便签窗口与共享会话

- [ ] 管理中心打开便签后，桌面出现对应便签窗口；两处文本同步。
- [ ] 在管理中心修改标题/正文，便签窗口更新；反之亦然。
- [ ] 关闭便签窗口（X / Ctrl+W）只隐藏该便签，`display_intent` 变为 Hidden，管理中心仍可见。
- [ ] 管理中心“显示便签”/双击便签恢复桌面窗口。
- [ ] 归档/回收站后对应桌面窗口消失；恢复后按 display intent 决定是否出现。
- [ ] 关闭管理中心选择“缩小到托盘”，桌面便签继续存在，托盘可重新打开管理中心。
- [ ] 关闭管理中心选择“退出应用”，先保存当前便签，再退出。

## 2. 托盘与启动

- [ ] 托盘只有一个图标；左键/双击打开管理中心。
- [ ] 托盘菜单新建、管理中心、全局隐藏/恢复、设置、退出均有效。
- [ ] 普通启动显示管理中心；`--startup` 启动不显示管理中心，只显示应显示的桌面便签。
- [ ] 设置页开启/关闭开机启动后，HKCU Run 实际值变化；`--startup` 参数存在。
- [ ] 开机启动失败时有明确错误，不显示“已启用”假状态。

## 3. 全局隐藏

- [ ] 全局隐藏只隐藏窗口，不改变任何单张 `display_intent`。
- [ ] 全局恢复只显示 Active + Visible；Hidden 仍不显示。
- [ ] 隐藏期间在管理中心对单张执行“显示便签”，只出现该张。
- [ ] 重启且 GlobalHidden=true 时，桌面便签不显示。

## 4. 快捷键

- [ ] 默认 Ctrl+Alt+N/M/H 分别新建、打开管理中心、全局隐藏/恢复。
- [ ] 修改/留空快捷键后实际重新注册；留空后不再响应。
- [ ] 与其他程序冲突时逐项提示错误码，不伪装成功。
- [ ] 输入法/普通文本输入不被快捷键截获。

- [ ] 断开副屏后重启/显示设置变化，窗口回到最近可用工作区且标题栏可操作。

## 6. 可访问性与键盘

- [ ] 仅键盘完成主要流程（见 `C5-错误UX清单.md`）。

- [ ] 空状态、错误、冲突、批量部分失败均有说明与操作。
