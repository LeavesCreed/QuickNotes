## 4. WPF 冒烟与 UI 自动化

### 4.1 启动冒烟

- 普通启动：进程保持运行，管理中心出现。
- `--startup`：进程保持运行，管理中心不显示；应显示的桌面便签由 `NoteWindowManager` 处理。
- 诊断日志无错误；冒烟只使用临时数据根。

### 4.2 UI 自动化证据

使用 Windows UI Automation 对真实 WPF 窗口执行：

| 场景 | 实际结果 |
|---|---|
| 点击“新建” | 便签窗口立即出现，不等待首次自动保存 |
| 新建后键盘焦点 | 焦点元素为 `ControlType.Edit`、名称“便签正文”，`HasKeyboardFocus=True` |
| 归档恢复 | “恢复”按钮在归档页启用；点击后 lifecycle 从 Archived 变为 Active，display intent 保持 Hidden |
| 管理端→便签端同步 | 管理中心修改正文，便签窗口更新 |
| 便签端→管理端同步 | 便签窗口修改正文，管理中心正文实时更新，无需切换便签 |
| 顶栏配置刷新 | 设置保存后，已存在便签窗口增加“颜色”直接按钮 |
| “更多”菜单 | 点击后找到“隐藏便签”等菜单项 |
| 顶栏直接动作 | 已配置时显示置顶/分类/颜色/字号/更多按钮 |

UI 自动化只验证结构与焦点/值传播，不替代真实鼠标、托盘、Alt+Tab、输入法和视觉检查。
