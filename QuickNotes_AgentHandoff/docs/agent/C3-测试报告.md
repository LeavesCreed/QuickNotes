## 4. 关键行为证据

- **schema v2**：便签新增颜色/字号/逻辑窗口布局；`app_settings` 单行乐观锁；`database_meta` 保存数据库身份与变更序号；设备设置独立 `device-settings.json`，不进入备份。
- **迁移**：v1→v2 在单事务内完成，提交前做完整性/外键/`user_version` 校验；迁移前生成并验证原始 DB 保护快照；失败保留 v1 与原文件。
- **变更检测**：替换启发式 SQL 指纹为 `schema=2;db=<guid>;seq=<n>`；所有便签/分类/标签/设置写事务同事务推进；回滚不推进。
- **快照基线**：成功日备份使用快照内 marker 写状态；快照期间新增编辑不会被误判为已备份；失败/取消不推进基线；旧状态指纹触发一次保守备份。
- **恢复兼容**：v1 包先用原 manifest 哈希验证原始库，再迁移暂存库、轮换身份，按目标哈希切换/核对；v2 包直接恢复同样轮换身份；未来版本拒绝。
- **草稿 v2**：新字段随编辑器/草稿保存；v1 草稿可按默认外观读取，不影响 C2 恢复。
