## 1. 结论与范围

C5 在 C2–C4 的保存/草稿/生命周期/备份恢复闭环之上完成管理中心与桌面行为：

- 管理中心：Active/归档/回收站导航、搜索、分类/标签筛选、排序、多选、批量操作、整体撤销、副本。
- 分类/标签：创建、重命名、颜色、删除转移、合并；便签分类/标签编辑与同步。
- 生命周期：归档/取消归档、移入回收站、恢复、永久删除；归档恢复按 PRD 恢复 Active+Hidden。
- 桌面：独立便签窗口、共享编辑会话、任务栏/Alt+Tab 工具窗口策略、单张隐藏/显示、置顶。
- 托盘/关闭/启动：唯一托盘图标、关闭三选项、`--startup`、HKCU Run 显式开机启动与状态核验。
- 全局隐藏：只控制桌面窗口，不改变单张 `display_intent`。
- 快捷键：三个可配置/禁用的全局快捷键、冲突/注册失败逐项提示。
- 窗口找回：逻辑 DIP 布局、显示器断开的最近工作区 clamp、显示绑定（设备设置，不进入备份）。
- 交互：新建便签立即出窗口并聚焦正文；管理端/便签端双向同步；顶栏动作实时刷新；“更多”菜单可展开。

前置条件：C3 schema v2/迁移/变更序号、C4 备份恢复 UI/调度/冻结已通过自动化回归。
