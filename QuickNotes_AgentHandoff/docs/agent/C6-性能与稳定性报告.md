## 7. 口径与限制

1. **UI 启动是代理：** 只等待真实便签窗口可见和 render dispatcher idle，不查询 UIAutomation 树、不点击控件、不测首次绘制/输入法；真实鼠标、托盘、热键、多屏仍为人工项。
2. **备份/恢复是服务代理：** dispatch/first-progress 不是备份中心 UI 完成；无 C0 预算。
3. **种子/active 差异：** 1,000 张种子中 919 张 active（其余归档/回收站）；UI/服务证据同时记录 `noteCount=919` 与 `totalNoteCount=1000`，验收形状要求 total ≥1,000、active ≥20。
4. **增长阈值未确认：** 15% 工作集/50 句柄只作为诊断（`diagnostic=true`、`thresholdConfirmed=false`），不使 2h 运行失败；300 MiB 峰值仍是确认门禁。
5. **UI 探针会短暂显示真实便签窗口** 于当前桌面；不创建托盘/热键/HKCU/管理工作区。只应在交互桌面运行。
6. **无生产性能修复：** 未发现可归因的生产性能缺陷，未修改生产行为；finding 仍开放。
7. **未覆盖：** 休眠/唤醒、真实显示器断开、混合 DPI、2 小时以上、真实用户数据规模、网络/外接备份设备。
