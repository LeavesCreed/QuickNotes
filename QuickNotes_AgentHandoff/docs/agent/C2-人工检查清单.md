## 3. 人工复现步骤

```powershell
# 构建
dotnet build QuickNotes_AgentHandoff\QuickNotes.DataPrototype.sln

# 首次启动（临时数据根，不要指向真实数据）
$root = Join-Path $env:TEMP ("QuickNotes-C2-Manual-" + [guid]::NewGuid().ToString("N"))
dotnet QuickNotes_AgentHandoff\src\QuickNotes.Desktop.Wpf\bin\Debug\net10.0-windows\QuickNotes.Desktop.Wpf.dll --data-root $root

# 主流程：新建 → 输入标题/正文 → 等待自动保存 → 关闭 → 再次启动确认内容
# 草稿流程：输入后在 300ms 内用任务管理器结束进程（或关闭时保留草稿），重开点击“草稿恢复”
# 关闭保护：输入后立即点窗口 X，观察保存与提示；选择“取消/保留草稿”
# 冲突/未知：需要并发改库或故障注入，无法构造时保持“未运行”
# 第二实例：保持工作区窗口，再执行一次上面的 dotnet 命令
```

- 仅使用合成便签/临时目录；不要使用真实用户便签、草稿或备份。
- 视觉检查覆盖：状态文字（已修改/保存中/已保存/保存失败/版本冲突/保存结果未知）、草稿状态、错误提示、冲突面板按钮、草稿恢复窗口、关闭提示。
- 未执行的项保持“未运行/待执行”，不得改为通过。
