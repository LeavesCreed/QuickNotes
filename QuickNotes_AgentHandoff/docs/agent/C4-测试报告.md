## 4. 关键行为证据

- **首启/目录**：未配置目录时自动备份不启用；选择目录校验绝对路径、存在、可写、与数据根分离；目录切换不搬移/删除旧备份。
- **调度**：Ready 后立即检查，随后 15 分钟周期；任务不重入；唤醒触发补检查；失败写运行状态并在下一周期重试。
- **手动备份/列表/校验/删除**：手动包不参与留存；列表按 manifest 时间倒序；可完整校验；只允许删除 `Manual` 包；日/周/损坏包不可从此删除。
- **恢复确认**：预检显示备份时间/类型/format/schema/便签/分类/标签计数、当前计数、草稿数、迁移需求和整库替换说明；设备设置不恢复。
- **冻结/失效**：恢复前冻结编辑、写草稿、保存在途内容；保存/草稿失败阻止恢复；旧 `NoteEditorSession.Invalidate` 拒绝迟到编辑/保存；失败后重开当前便签。
- **进度/取消**：Preflight/ProtectionSnapshot/Staging/Migrating/Switching/Verifying/Completed/Failed/RolledBack；切换前可取消，切换/校验不可取消。
- **恢复后**：宿主重建 `StartupCoordinator`、写入门、编辑/备份服务并触发窗口替换；草稿写恢复前边界；旧窗口关闭。
- **恢复失败**：回退成功显示已回退；回退失败保持写入阻断并显示保护快照/数据目录提示。
- **设备设置**：`device-settings.json` 不进入备份，恢复测试断言文件字节不变。
