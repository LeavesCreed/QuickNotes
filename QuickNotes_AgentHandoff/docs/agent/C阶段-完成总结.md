## 4. 技术评审结论

**决定：附条件保留（conditional retain），不冻结、不正式发布。**

依据：

1. 核心数据正确性、保存/草稿、备份/恢复、单实例/阻断状态、C5 桌面行为与 C6 自动化/强杀/恢复不变量已有分层证据。
2. C7 试用构建可构建/可运行，Release 全量与漏洞审计通过。
3. C6 仍有关闭级缺口：2h 长稳、F01/F04/F05/F06、A-11、UI 级 M02/M03；性能聚合 NOT RUN；首次冷启动 5,406.84 ms 尾部未纳入 p95。
4. `.NET 10 + WPF + SQLite` 满足当前原型的数据/桌面需求，但单进程/rollback journal/未加密备份等边界需在发布阶段重新评估。

冻结条件：C6 阻塞关闭或书面风险接受；2h PASS；真实 VHD/ACL 补跑；A-11 重测；UI 级 M02/M03 人工通过；Release/首次冷启动预算决策；全量与 WPF 冒烟复跑。
