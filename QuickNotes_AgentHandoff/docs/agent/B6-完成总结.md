## 1. 结论

- 构建：**0 警告，0 错误**
- NuGet 漏洞审计：**7 个项目均无已知漏洞包**

## 4. 故障矩阵与结果

| 故障 | 注入方式 | 实际断言 | 结果 |
|---|---|---|---|
| 数据库磁盘满 | 真实连接 `max_page_count=page_count`，512 KB 正文 | `StorageUnavailable`、`sqlite_full`、不重试、`Attempts=1`；之后库可写且便签不存在 | 通过 |
| 数据库写入拒绝 | 只读 DB 文件 | `StorageUnavailable`、`operation=create; error=sqlite_readonly`、不重试；原便签保留、新便签不存在 | 通过 |
| 备份快照磁盘满 | 快照提供者写部分文件后抛 `SnapshotFailed` | `SnapshotFailed`；无最终 ZIP/临时目录；源库可读 | 通过 |
| 备份包写入磁盘满 | 包存储抛 `PackageWriteFailed` | `StorageUnavailable/PackageWriteFailed`；无最终包/临时残留；源库可读 | 通过 |
| 备份取消 | 包存储写部分文件后抛 `OperationCanceledException` | 取消上抛；无最终包/临时残留；源库可读 | 通过 |
| 备份损坏/校验失败 | 篡改包内 `notes.db` | 校验器拒绝 SHA-256 不匹配；验证目录无残留；B5 恢复端到端拒绝且当前库不变（基线测试） | 通过 |
| 恢复 staging 失败 | 提取器预检成功、staging 抛 `DestinationUnavailable` | `VerificationFailed/StagingUnavailable`；保护快照保留；当前库不变；staging 清理；写入门未阻断 | 通过 |
| 恢复切换失败 | 真实 `FileShare.None` 锁住当前库，`File.Replace` 失败 | `SwitchFailed`；当前库不变；保护快照保留；staging 清理；后续保存成功 | 通过 |
| 恢复回退失败 | 真实切换后报告不一致状态，回退抛 `RollbackFailed` | `RollbackFailed/WritesBlocked`；写入门阻断；保护快照与 staging/`rollback.db` 保留；恢复提示含当前库路径；后续保存 `StorageUnavailable`+`database_writes_blocked` | 通过 |
| 留存清理失败 | 待删日备份 ZIP 设只读 | 日备份成功；`retention_delete_failed` 警告；只读文件保留、其他待删文件删除；周/日/手动保留点存在；状态文件写入；源库可读 | 通过 |
| 备份目录不可用 | 备份路径被文件占用 | `Failed(DestinationUnavailable)`、可重试；占用文件不变；源库可读 | 通过 |
| 旧/新写入竞争 | 两个协调器并发同 `expectedVersion` 更新 | 恰好一个 `Saved`、一个 `Conflict`；版本 2；内容等于胜者 | 通过 |

## 6. 审查与修复

- [建议] `FaultInjectionDailyBackupTests.CreateService` 的 `backupDirectory` 参数未使用 → 删除参数并更新调用。
- [建议] 只读库测试仅断言诊断包含 `sqlite_`，无法区分错误 → 精确断言 `operation=create; error=sqlite_readonly`。
- [建议] 并发测试在已断言内容等于胜者后重复断言内容集合 → 删除冗余断言。
- [建议] `RestoreIntegrationTests` 与 B6 辅助类重复实现包篡改 → 统一使用 `FaultInjectionTestData.CorruptDatabaseEntry`，删除重复私有方法。
- [说明] `configureConnection` 可执行任意连接级命令，钩子抛出的 `SqliteException` 会按 `open` 操作翻译；该钩子仅用于测试注入，默认 `null`，已在 ADR 记录。
- [说明] 注入式磁盘满验证协调器映射与清理，不等价于真实卷耗尽；真实卷/崩溃矩阵留后续（ADR 已声明）。

## 7. 已知限制

- 未模拟真实耗尽磁盘卷、系统级 ACL 拒绝、强杀进程或真实崩溃；使用等价可重复注入覆盖失败语义。
- 只读属性与 `FileShare.None` 阻止 `File.Replace` 的行为依赖 Windows；目标平台 Windows 11 x64。
- 回退失败使用包装存储模拟切换歧义；真实 `File.Replace` 回退成功由 B5 集成测试覆盖。
- 并发测试接受任一写入者获胜，只断言恰好一个成功/一个冲突与无丢失更新。
- 不覆盖 WAL、跨进程恢复锁、UI 确认/恢复入口与崩溃遗留 staging 清理。
- 备份损坏的恢复级验证复用 B5 基线测试；B6 新增校验器级真实篡改测试。
