## 3. 人工复现步骤

```powershell
dotnet build QuickNotes_AgentHandoff\QuickNotes.DataPrototype.sln
$root = Join-Path $env:TEMP ("QuickNotes-C4-Manual-" + [guid]::NewGuid().ToString("N"))
$backup = Join-Path $env:TEMP ("QuickNotes-C4-Backup-" + [guid]::NewGuid().ToString("N"))
New-Item -ItemType Directory -Path $backup | Out-Null
dotnet QuickNotes_AgentHandoff\src\QuickNotes.Desktop.Wpf\bin\Debug\net10.0-windows\QuickNotes.Desktop.Wpf.dll --data-root $root
# 首启选择 $backup；创建工作区便签并等待自动保存
# 打开“备份与恢复”：手动备份、刷新、校验、删除手动备份
# 修改便签后等待自动调度或点击重试检查
# 选择备份恢复：查看确认信息，测试取消/成功/失败路径
# 恢复成功后重开应用，检查草稿恢复窗口和状态
```

- 仅使用临时数据根和独立临时备份目录；不访问真实用户便签/备份。
- 恢复失败/回退失败需使用合成包或故障注入，无法构造时标“未运行”。
- 视觉检查覆盖目录提示、状态文本、列表、确认对话框、进度阶段、结果/阻断提示。
