## 3. 人工复现步骤

```powershell
# 构建
dotnet build QuickNotes_AgentHandoff\QuickNotes.DataPrototype.sln

# 首次启动（临时数据根，不要指向真实数据）
$root = Join-Path $env:TEMP ("QuickNotes-C1-Manual-" + [guid]::NewGuid().ToString("N"))
dotnet QuickNotes_AgentHandoff\src\QuickNotes.Desktop.Wpf\bin\Debug\net10.0-windows\QuickNotes.Desktop.Wpf.dll --data-root $root

# 第二实例：保持第一个窗口运行，再执行一次上面的 dotnet 命令（不带 --single-instance-probe）
# 正常退出：在窗口点击“退出”或用窗口 X
# 缺失库：关闭窗口，删除 $root\notes.db（保留 application-state.json），再启动
# 损坏库：关闭窗口，把 $root\notes.db 改为非 SQLite 文本，再启动
# WAL：关闭窗口，创建 $root\notes.db-wal 空文件，再启动
# 恢复：在“从已验证备份重建”选择测试备份 ZIP；当前库损坏时确认隔离
```

- 仅使用合成便签/临时目录；不要使用真实用户数据。
- 视觉检查覆盖：窗口标题、状态/原因、数据/日志路径、按钮启用状态、错误提示、关闭/退出。
- 未执行的项保持“未运行”，不得改为通过。
