## 6. 故障/数据保护验证

- 首次初始化在无状态/无数据证据时执行；写入 `Initializing` 后才建库，失败保留状态、不写 Ready。
- 状态缺失但 DB/草稿/恢复产物存在 → 只读诊断，不初始化/不删除。
- DB 缺失/损坏、状态损坏、WAL sidecar、恢复日志未完成/损坏 → NeedsRecovery/ReadOnlyDiagnostic；不自动建库、不删 sidecar/恢复文件。
- 恢复日志阶段持久化契约已建立；C1 读取识别，C4 在真实恢复流程写阶段。
- 缺库/损坏/阻断恢复：B3 完整校验 + 同卷 staging + 发布后 SHA-256/counts 校验；隔离旧库；失败保留 staging/quarantine，不报成功。
- 持久阻断先写状态再内存阻断；状态写失败仍内存阻断并记录；重启读取阻断，不自动清除。
- C1 扫描恢复目录/保护快照/临时文件/隔离库，默认全部保留。

- WPF 视觉/关闭/多屏/DPI/真实强杀/卷耗尽/ACL/性能均未运行；不能作为发布验收。
