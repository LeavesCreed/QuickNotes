## P0 优先级映射（C 阶段）

1. C1：单实例先于数据资源、首次/缺失/损坏/阻断路径、跨重启阻断、缺失库重建、最小诊断 UI。
2. C2：编辑/保存/草稿闭环；不得误报保存成功。
3. C3：schema v2/迁移/字段策略/确定性变更标记。
4. C4：备份/恢复 UI 与宿主调度；旧会话失效。
5. C5：托盘/快捷键/分类标签/生命周期/多屏 DPI。
6. C6：真实故障/性能/稳定性。
7. C7：试用构建/文档/技术评审。

## 明确延期

- 导出、安装器/自动更新、备份加密、云同步、增量备份、Rust FFI。
- 多实例写入、WAL（如需引入，单独 ADR/评估）。
- 未在 C0/C1 实现的 PRD 功能不得写成已通过。
