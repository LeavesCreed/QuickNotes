## 7. 隔离与可重复性

- 所有测试使用临时目录与合成便签，不读取/写入真实用户数据。
- 故障注入测试在 `finally` 中恢复只读属性、释放文件锁；临时目录由测试辅助类清理。
- 测试依赖 Windows 文件共享/只读语义与 SQLite 原生库；跨平台结果不作承诺。
- 本次只执行一次全量套件，未做多次重复运行的稳定性统计；如用于发布验收，应增加重复执行与真实故障环境测试。
- 复现：按第 2 节命令在仓库根目录执行；首次需要 NuGet 还原。
