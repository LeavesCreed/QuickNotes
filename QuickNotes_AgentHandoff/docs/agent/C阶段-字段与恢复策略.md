补充规则：

- `global_hidden` 是全局意图，**不得改写**单张便签的 `display_intent`；全局恢复只显示原本 `Visible` 的便签（PRD 5.2）。单张便签在全局隐藏期间被单独显示时，只改变该便签自身意图。
- 窗口布局存储逻辑值；显示器标识、跨屏坐标修正属于本机运行时映射，不进入备份（PRD 4.2、11.5）。
- 设备设置文件中的快捷键“配置”与“实际注册状态”分离；注册失败不得写成已启用（PRD 9）。

## 3. 版本与兼容矩阵

| 当前应用 | 当前 DB schema | 包内 DB schema | 结果 |
|---|---:|---:|---|
| C2（v1 代码） | 1 | 1 | 现有直接恢复路径，C3 不改其行为 |
| C3 | 2 | 2 | 直接预检/恢复；恢复后轮换数据库身份 |
| C3 | 2 | 1 | 以原 manifest 哈希验证包内原始库 → 迁移暂存库 v1→v2 → 轮换身份 → 按目标哈希切换/核对 |
| C3 | 1 | 1/2 | 正常启动必须先迁移当前库；恢复预检拒绝 v1 当前库，提示先完成启动迁移 |
| 任意 | 未知 >2 | 未知 >2 | 拒绝；不降级、不半迁移、不创建空库继续写入 |
| C2（v1 代码） | 2 | 任意 | 不支持；v1 代码不得打开 v2 库，需由 C3 迁移/提供兼容路径 |

- manifest `formatVersion` 保持 1；`schemaVersion` 允许 1 或 2（恢复侧校验，创建侧写当前 2）。数据库 schema 版本与备份包格式版本分别管理。
- ZIP 条目仍严格为 `manifest.json` + `notes.db`，不因 schema 升级新增条目。
- 迁移保护快照是原始 DB 文件，不是备份包；不得被备份目录扫描/留存当作备份包。
- 恢复哈希语义：先按原 manifest 验证包内原始库，再校验迁移后的目标库并记录目标校验值；切换后按目标校验值核对，不得拿迁移后的库直接比原包哈希。
- 上表是设计矩阵；C3 Task 4–6 实现并以测试证明。Task 1 未运行迁移/恢复测试。

## 5. C4/C5 后续接线点

- **C4（备份 UI、调度、恢复交互）：** 预检显示 schema/格式版本、数量与设备设置策略；恢复后刷新全局隐藏、通知、顶栏、字号与窗口；恢复不修改 `device-settings.json`；成功基线只使用包内快照的变更标识；草稿先捕获并标记恢复前来源；提供迁移保护快照的诊断/恢复入口与清理策略。
- **C5（管理功能与桌面行为）：** 设置页编辑默认字号、通知、顶栏；便签颜色/字号/窗口布局交互；全局隐藏恢复遵守单张意图；快捷键实际注册、冲突与禁用；开机启动仅在用户明确开启时注册并核验；分类/标签/生命周期写入走统一协调器并同事务更新变更标识。
- **C3 内部前置：** Task 2 写 schema/仓储/设备设置存储并在写入前调用 `NoteRules`；Task 3 实现变更序号；Task 4 迁移；Task 5 快照基线；Task 6 恢复兼容；Task 7 草稿 v2；Task 8 全量验证。

## 6. 写入、校验与默认值不变量

1. 写入便签前必须调用 `NoteRules.ValidateColor`、`ValidateFontSize`、`ValidateWindowLayout`；非法值抛参数异常，不静默纠正。
2. `FollowCategory` 时 `ColorHex` 必须为 null；`Manual` 时必须为 `#RRGGBB`。字号 null 表示跟随全局；非 null 必须在 8–72（候选）。
3. 窗口布局四值同空或同非空；宽度/高度必须为正且有限；`left/top` 可为负。
4. `ApplicationSettings.CreateDefault(now)` 产生 `Version=1`、字号 16、全局隐藏 false、通知 true、顶栏默认配置，`UpdatedAtUtc=now`；持久化前调用 `Validate`。
5. `TopBarConfig` 默认 `[Pin, More]`；最多 8 个、不得重复、必须已定义。
6. `DeviceSettings` 格式版本必须为 1；备份目录为 null 或绝对路径；显示器绑定 key/value 非空；快捷键为 null（禁用）或非空字符串。设备设置原子写入，未知版本拒绝覆盖。
7. 所有进入备份的写入必须与变更标识同事务提交（C3 Task 3）；事务回滚不得推进标识。
8. 设备配置、草稿与迁移保护快照不进入备份，恢复不得盲目覆盖本机状态。
9. 未知未来 schema/格式版本拒绝，不以空库或降级方式继续。
