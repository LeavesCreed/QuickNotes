## 5. 集成结论

- C1 新建 `QuickNotes.Desktop.Core`（无 WPF）与 `QuickNotes.Desktop.Wpf`，组合既有 Application/Infrastructure 服务；不搬迁 A 原型代码。
- 在打开数据库/草稿/后台任务前取得单实例所有权。
- 数据根默认 `%LOCALAPPDATA%\QuickNotes`，测试/手动可用 `--data-root` 覆盖；备份目录 C4 配置，C1 仅提供 `--backup-dir` 诊断扫描。
- C1 只交付启动/诊断窗口；编辑器、托盘、快捷键、schema v2、备份管理 UI、真实故障矩阵留 C2–C7。
- 具体 PRD 映射、状态机、ADR 与风险见后续 C0 文档。
