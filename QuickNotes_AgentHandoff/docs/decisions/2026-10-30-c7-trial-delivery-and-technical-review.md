## 决策

1. **C7 交付为条件交付（conditional trial delivery），不是 C 阶段整体通过，也不是发行版。**
2. **`.NET 10 + WPF + SQLite` 附条件保留（conditional retain），不冻结。** 当前证据足以支持试用与继续评审，但不足以冻结发布技术选型。
3. **试用构建以框架依赖发布为主**（24 文件/约 3.8 MB，需 WindowsDesktop Runtime 10.0.x）；自包含发布已构建（492 文件/约 183 MB）但不作为默认分发形态。
4. **不得宣称：** C 阶段整体通过、C6 已通过、C7 已冻结/可正式发布、2h/真实 VHD/A-11/UI 级恢复检查已通过、首次冷启动 ≤3 s。
5. **冻结/发布前置条件：**
   - C6 2h 长稳 PASS，或用户书面风险接受；
   - C6-F01/F04/F05/F06 在提权 + Hyper-V 环境补跑，或书面风险接受；
   - A-11 实机重测，或明确保留为已知问题；
   - C6-M02/M03 真实 WPF 恢复窗口/文案/诊断入口人工通过；
   - Release 试用构建重跑 UI 启动门禁，并决定首次冷启动预算；
   - 全量回归、漏洞审计、WPF 冒烟复跑通过；安装器/签名/加密等发布工程若纳入，另立范围。
6. **C7 交付物只使用临时数据根/合成数据**；不修改生产代码；不写入真实用户数据、HKCU Run 或真实恢复。

## 后果

**正向：**

- 评审者可按 README/试用指南构建、发布、启动并试用当前功能；数据/备份兼容与限制可查。
- 核心数据/恢复闭环与桌面行为有 C1–C6 分层证据，C7 试用构建可运行。
- 技术评审结论有明确事实依据，不把“构建成功”冒充“阶段通过”。

**负向/保留：**

- 试用构建不具备发行级质量保证；2h/真实 VHD/A-11/UI 级恢复检查未关闭。
- 首次冷启动尾部、Release 性能未纳入门禁；真实用户规模/磁盘增长未测。
- 无安装器/签名/导出/OS 通知/自动更新/云存储/备份加密；无 WAL/多实例写入支持。
- 恢复回退失败仍会持久阻断写入，解除依赖显式验证/人工处理。
